# Şam Çekimi Ekip Rehberi

Şam Uluslararası Recep Tayyip Erdoğan Türk Okulu tanıtım filminin 17–18–19 Kasım 2026 çekimi için ekip rehberi.

Sayfa: `index.html`. Film özeti, çekim kartları, çekim takip listesi (tekrar, saat, iyi tekrar, not; paylaşım ve CSV), üç günlük program, ekipman listesi, kurallar ve hazırlık listeleri içerir. İnternetsiz de açılır; işaretler yalnızca açan cihazda saklanır.

Senaryonun tamamı: `Sam_RTE_Turk_Okulu_Senaryo_v010.pdf` (v010, 14 Kasım 2026). Rehberin Film sekmesinden açılır.
