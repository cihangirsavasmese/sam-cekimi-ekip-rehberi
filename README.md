# Şam Çekimi Ekip Rehberi

Şam Uluslararası Recep Tayyip Erdoğan Türk Okulu tanıtım filminin 17–18–19 Kasım 2026 çekimi için ekip rehberi.

Tek dosyalık bir sayfa: `index.html`. Film özeti, çekim kartları, üç günlük program, ekipman listesi, kurallar ve hazırlık listeleri içerir. İnternetsiz de açılır; işaretler yalnızca açan cihazda saklanır.
